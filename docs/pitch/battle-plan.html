HackUTD 2026 · Zero Day · Incident 0x01 · Team of 3 · 12 build hours
IRONGUARD

Intercept the scam before the strike.

A dragonfly-inspired trajectory model forecasts where a text conversation is heading. A leaf-sheep-inspired distillation loop learns brand-new scams without reading anyone's texts. A Nemotron agent and a Photon iMessage/SMS number turn the forecast into protection.

01 · The gapFilters ask "is this a scam?" We ask "where is this going?"

Multi-turn scams open innocently. Per-message filters only react at the strike, when the link or money ask arrives, and by then the victim is hooked. The strongest shipping system we found, Google Messages Scam Detection on Gemini Nano, is reported to run only on recent flagship Android phones.

Gap 1 · Forecast

Lead time and honest confidence

PreyNet predicts scam family, next stage and turns until the ask from turn 1–2, with calibrated probabilities and an explicit "uncertain" band. New metric: turns of warning before the strike.

Gap 2 · Zero-day

New scams in minutes, zero customer data

One-sentence alert → Nemotron synthesizes conversations → an ~82 KB chloroplast trains in seconds → phones absorb it and run it locally.

Gap 3 · Reach and action

Any phone, real next steps

Forward to a Photon number from iPhone or Android. The Safeguard Agent verifies the claimed brand, number and domain, locks links, and offers one-tap safe actions.

02 · The model (main focus)How we train it

Everything below is specified in docs/MODEL_SPEC.md. Each biology idea maps to a concrete part of the network, and every number shown to judges comes from eval_summary.json.

1 · Algae dataNemotron 3 Nano writes ~2,000 conversations: 6 scam families + benign, 40% hard negatives, critic-filtered
2 · Turn vectors"[THEM]/[ME]" + MiniLM 384-d, cached; same embedder in the browser
3 · PreyNetLinear→causal GRU→CSTMD1 attention→heads: family · next stage · turns-to-strike. ~160k params
4 · CalibrateTemperature scaling on val; ECE; lock-on hysteresis 0.70 / 0.40
5 · ChloroplastZero-day: MLP 640→32→1 on frozen features, <10 s CPU, ~82 KB, ships to phones

Headline metrics
  • EWR@k: early-warning rate at turn k, at 1% false alarms
  • Lead time: turns of warning before the ask
  • ECE before/after calibration
  • Zero-day: held-out family before/after the chloroplast, plus a sample-efficiency curve
Leakage defenses
  • Human-written test set, never trained on
  • Conversation-level splits (no prefix crosses splits)
  • Near-duplicate removal; no label words in text
  • Thresholds, temperature and early stopping on val only
Baselines it must beat
  • B0 keyword rules on the latest message
  • B1 TF-IDF + LR, latest message
  • B2 MiniLM + LR, latest message
  • B3 bag-of-turns (context without order)

05 · No merge hellEight rules, enforced by the repo itself

  1. Ownership by folder, blocked by a pre-commit hook in every worktree (tested), plus CODEOWNERS and CI.
  2. No shared progress file. Each member logs to progress/X.md; only B edits PROGRESS.md.
  3. Contracts first: 7 JSON Schemas, frozen at M0, additive-only after.
  4. Mocks from hour one: stub model, mock API, mock UI data. Nobody waits.
  5. No root manifests. One lockfile per service, one owner each.
  6. One writer per artifact: B writes datasets, A writes model files. Both get express-lane PRs.
  7. Merge commits only on GitHub (squash breaks the next rebase). Fixed order: contracts → ml → api → web/bridge.
  8. Red smoke means a 10-minute fix or a revert. Never debug on main.

07 · TracksOne product, three scorecards

T-Mobile · Safe Signal

Before: forecast at turn 1–2. During: locked links, Cool-Down Shield, verified official numbers. After: consented report → reef → chloroplast for everyone. Calibrated confidence, on-device privacy, our own synthetic data.

NVIDIA · Nemotron beyond a chatbot

No chat window. Two multi-step agents: the Algae red-team factory (plan → generate → critique → dedupe → train) and the Safeguard agent (4 real tools → schema-valid card). Nemotron is the teacher in a distillation pipeline.

Photon

A real iMessage/SMS number: forward a thread, get the forecast and safety card back, reply 1/2/3 to act. Per-thread memory, edge cases handled, anyone can text it tomorrow.

Check the Hackerpack or Discord at H0 for a limit on sponsor tracks. If it's two, submit to T-Mobile + NVIDIA and keep Photon in the demo.
